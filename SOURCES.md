# Sources and scope

Reviewed: 2026-10-23. This skill contains original production guidance informed by the sources below. No external implementation or asset pack is bundled.

- [video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft): shot planning, small previews, iteration and render review. Its product-video templates, framework-specific implementation and mandatory collaboration/subagent policies are not adopted. Prior research also inspected the [SunCl8 snapshot](https://github.com/SunCl8/video-shotcraft-skill/blob/main/SKILL.md); it must not be treated as proof of the upstream repository's current contents.
- [SkillMedev video-storyboard](https://github.com/SkillMedev/skills/blob/main/skills/video-storyboard/SKILL.md): separate scene/shot planning from rendering mechanics. Its product-launch story formula is not a universal requirement here.
- [Remotion Agent Skills](https://github.com/remotion-dev/remotion/blob/main/packages/skills/README.md): consult specialized skills for actual renderer implementation; Remotion is not a dependency of this skill.
- [An Interdisciplinary Guideline for the Production of Videos and Vision Videos by Software Professionals](https://arxiv.org/abs/2001.06675): preproduction, production, postproduction and viewing as distinct concerns. Its application domain does not establish universal artistic or engagement criteria.
- [ComfyUI documentation](https://docs.comfy.org/): source for current workflow/node/model compatibility when a project uses ComfyUI; no particular workflow or checkpoint is bundled.

These are references, not claims that all recommended tools are installed, free, compatible, or empirically superior. Check current official documentation and applicable licenses when choosing an implementation.
